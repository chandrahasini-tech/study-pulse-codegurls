# StudyPulse – Student Improvement Tracker

StudyPulse is a smart productivity application designed to track and analyze a student’s actual learning progress. Unlike traditional planners that focus only on schedules, StudyPulse focuses on execution, consistency, and improvement.

---

## Features

* Daily study logging (subject, time spent, topics covered)
* Self-rating system (Revise, Need More Time, Perfect)
* Subject-wise and overall progress tracking
* Weekly analysis and comparison
* Identification of strongest and weakest subjects
* Optional AI-based feedback using Gemini API
* Goal-based tracking (hours, marks, syllabus)
* Improvement trends and insights

---

## Problem Statement

Students often create study plans but fail to track their actual learning. This leads to a lack of clarity about their preparation level. StudyPulse addresses this by recording daily study activity and providing meaningful insights into performance and improvement.

---

## Tech Stack

* Frontend: React / TypeScript
* Styling: Tailwind CSS
* Icons: Lucide React
* Animations: Motion
* AI Integration (optional): Google Gemini API

---

## Working

1. User sets subjects, goals, and exam date
2. Logs daily study activity
3. Application stores and processes the data
4. Displays progress, trends, and insights
5. AI (optional) generates feedback and suggestions

---

## Outputs

* Total study time
* Subject-wise time distribution
* Weekly comparison
* Strongest and weakest subjects
* Goal readiness estimation
